# CONDOMINAR · Sitio web v2

Rediseño del sitio de CONDOMINAR (software de administración de condominios, Quito, Ecuador).
HTML + CSS + JS puro, sin dependencias ni proceso de build.

## Estructura
```
index.html          Página completa (estilos y script incluidos)
assets/img/         Logo, mascota, halo y fotografías
assets/fonts/       Ubuntu (400/500/700) e Inter (variable)
```

## Publicar con GitHub Pages
1. Sube el contenido de esta carpeta a la raíz de un repositorio.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. El sitio queda disponible en `https://<usuario>.github.io/<repositorio>/`.

Para usar un dominio propio (por ejemplo condominar.com), agrega un archivo `CNAME` con el dominio y configura el DNS según la guía de GitHub Pages.
